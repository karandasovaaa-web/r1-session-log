## 4.1. Условия

Измерение времени выполнения выполнялось с помощью режима benchmark,
реализованного в программе. Использовался таймер time.perf_counter().

Измерялись отдельно:
- время чтения входного файла;
- время разбора и обработки событий.

Для оценки общего времени использовалась сумма времени чтения и обработки.
Оптимизатор кода не применялся, так как программа написана на Python 3.

## 4.3. График

На графике по оси X откладывается количество событий в журнале,
по оси Y — время обработки в миллисекундах.

## 4.4. Проверка гипотезы роста

Предполагаемая функция роста:

f(n) = n

Так как программа выполняет один проход по входному файлу и каждая
строка обрабатывается один раз, ожидается линейная зависимость.

| n | t(n), мс | f(n) | t(n)/f(n) |
|---|---|---|---|
|100|0.219|100|0.00219|
|500|0.589|500|0.00118|
|1000|0.844|1000|0.00084|
|5000|4.856|5000|0.00097|
|10000|6.678|10000|0.00067|
|50000|46.616|50000|0.00093|

Отношение остаётся примерно постоянным, поэтому гипотеза линейного роста
подтверждается.

## 4.5. Расхождения

На малых размерах входа наблюдаются отклонения из-за накладных расходов
интерпретатора Python, открытия файлов и работы операционной системы.
При увеличении размера входных данных зависимость становится ближе
к теоретической O(n).
